- **OQ-124-1** — *Resolved* (2026-10-19-plan124 pass) → findings §2.1: the frame container is the

- **OQ-124-2** — The **band-assembly rule**: each reply carries ~12 KB = 6 rows + a partial row of a

- **OQ-124-4** — The **pixel scale**: 8-bit single-channel is settled (1 byte per pixel; 0xFF invalid

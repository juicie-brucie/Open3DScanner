# 2026-10-21 — the T7 daemon bring-up: what ran, what blocked, and the four fixes

The first real T7 session on hardware. The daemon code is complete; this session exercised
it and produced the exact blockers.

## What ran

- **#178 probe — PASS** (`raw_capture --probe`, exit 0): `vid=0x2BC5 pid=0x0C03`, 7
  interfaces; three UVC VS — `0x81` Y8 480x300, `0x82` Y8 960x600, `0x83` YUY2 1280x800;
  HID interface 6, endpoint `0x85` interrupt, max packet 248, report descriptor 25 B.
  The IR/depth assignment is explicitly left to **OQ-169e**.
- **#171/#178 capture — BLOCKED** (exit 2): `not-configured` on the IR/depth endpoints;
  the table is unfilled. A configuration gap, not a code defect — and a circularity: the
  probe cannot fill the assignment it names.
- **#172 offline shim A/B — PASS**: the shim served the actual `raptor_client` from the
  #132 bundles — 132 frames, 0 empty, the 11-element `Bin(2304000)` array, SET accepted.
  This is **not** the same-scene vendor A/B (the vendor comparator is a different run and
  the depth has no vendor side).
- **#179 live source — BLOCKED** on three independent conditions: the helper is not
  claiming (`org.openscanner.helper` `Connection invalid`), OQ-169e, and the OB words
  (`e2/e3/e10`).
- **#175 telemetry — IR PASS / depth BLOCKED**: the `[timing]` line is live on IR (n=56,
  p50 119,727 us, p95 130,739 us, payload 15,033,194 B/s, first frame 244,826 us); the
  depth port times out on `start_stream0-2-10` after the IR session. The depth addendum's
  md timing line does not match its raw log; `prop=192` at raw:218 needs a re-read.
- **Session audit addendum**: the HEAD `823fd83` for the 2026-10-21 records; a metadata
  backfill (a commit sha, not a binary hash; the device/daemon gaps are
  coordinator-relayed).

## The four fixes dispatched

- **#180** (build3) — the live source's **OB words provider**: e2 (the time word; the
  #143 correction: e1=0), e3 (the OBFormat from the table), e10 (the stream index/light
  type); no defaults.
- **#181** (build2) — the helper's **user-scope XPC service**: a user LaunchAgent with
  the Mach service `org.openscanner.helper`, dev-signed, no per-run sudo; the shim's
  claim query.
- **#182** (build1) — the probe's **RPC↔UVC correlation mode**: assign IR/depth
  empirically with the vendor daemon streaming, read-only; print the table mapping.
- **#183** (recon2) — **OQ-169e**: the RPC→UVC interface map, the 1920x1200 RPC frames
  vs the 480x300/960x600/1280x800 UVC VS, and the OB-word mapping; the static answer or
  the exact empirical test.
